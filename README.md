# MDBM-TFBS

Predicting Transcription Factor Binding Sites Based on Multi-scale Dilated Convolution Fusion and Bidirectional Mamba

---

## 📂 Repository Structure

```
MDBM-TFBS/

├── Dataset/                # Example datasets and data preprocessing scripts
├── DNABERT/                # Pretrained DNABERT model
├── result/                 # Model predictions and evaluation results
├── save_model/             # Trained model 
├── utils/                  # Utility functions and helper scripts
├── main.py                 # Entry point for training and evaluation
├── model.py                # Model architecture definition
├── train.py                # Training pipeline script
├── README.md               # Project documentation

---


## 🚀 Usage

```bash
python main.py
```


## 📊 Data

* Example datasets are provided in the `Dataset/` folder
* Due to the large size of the dataset, it is not included in this repository. 
* Please contact us if you need access to the data.

---

## 📦 Pretrained Models

Pretrained models are not included in this repository due to size limitations.

Download links:

* DNABERT: [https://huggingface.co/zhihan1996/DNA_bert_3]

After downloading, place them in the appropriate directory.
